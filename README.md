# Data Platform Engineering

Professional learning journey focused on modern Data Engineering,
DataOps, Cloud Engineering and AI Engineering.

## About this repository

This repository documents a structured 9-month learning journey
designed to develop practical skills in building, automating,
deploying and monitoring modern data and AI platforms.

## Learning objectives

- Develop maintainable Python applications.
- Build reliable data pipelines.
- Implement testing and CI/CD practices.
- Orchestrate workflows with Apache Airflow.
- Develop analytics transformations with dbt.
- Design and deploy data solutions on Google Cloud.
- Build LLM and RAG applications.
- Explore AI agents, MLOps and LLMOps.
- Implement observability and production best practices.

## Main technologies

Python, SQL, Git, GitHub Actions, Docker, Apache Airflow,
dbt, PostgreSQL, Google Cloud Platform, FastAPI,
LLMs, RAG, MLflow and Langfuse.

## Learning approach

Each module includes:

- Learning objectives
- Technical concepts
- Practical exercises
- Hands-on projects
- Documentation
- Skills assessment

## Final project

An end-to-end Data and AI platform integrating data ingestion,
transformation, orchestration, cloud services and AI capabilities.
